This repository contains beginner-friendly C++ programs for programming practice.

## Programs

1. `01_vowel_or_consonant.cpp` — Check whether a character is a vowel or consonant.
2. `02_roots_of_quadratic_equation.cpp` — Find real or complex roots of a quadratic equation.
3. `03_check_leap_year.cpp` — Check whether a year is a leap year.
4. `04_ascii_values_english_letters.cpp` — Print ASCII values for `a-z` and `A-Z`.
5. `05_array_operations_switch_case.cpp` — Menu-driven array operations using `switch`: addition, subtraction, multiplication, largest/smallest element, and average.

## How to compile and run

You need a C++ compiler such as `g++`.

Example for the first program:

```bash
g++ 01_vowel_or_consonant.cpp -o vowel
./vowel
```

Replace the source filename and output name to run another program.

## Language

C++ (standard library; compatible with common C++11-or-later compilers).
